# Kodax — رحلتك تبدأ بكود

فيديو موشن غرافيك عمودي، 52 ثانية، 1080×1920، 30 إطاراً في الثانية.
نصوص عربية باللهجة العراقية ومؤثرات صوتية متزامنة مع الحركة، بدون موسيقى أو تعليق صوتي.

## المشاهد

| الوقت | الموضوع |
|---|---|
| 0–6 | تقديم Kodax وبدء رحلة البرمجة |
| 6–13 | بايثون، الذكاء الاصطناعي، الأمن السيبراني، تطوير الويب |
| 13–19 | كتابة وتشغيل الأكواد |
| 19–25 | حل التحديات وكسب نقاط الخبرة |
| 25–31 | التصنيفات على العراق والمحافظة |
| 31–38 | مشاركة الكود، الإعجابات، التعليقات، المتابعة والتواصل |
| 38–43 | مساعد Kodax |
| 43–48 | الشهادات التقديرية |
| 48–52 | ختام ودعوة لبدء التعلّم |

## الملفات

- `index.html`: التصميم والحركات والنصوص القابلة للتعديل.
- `assets/`: الشاشات الثماني المستخرجة من الصور المرجعية، شعار التطبيق، الخط والمؤثرات الصوتية.
- `create_sound_effects.py`: توليد المؤثرات الأصلية؛ يتطلب Python وNumPy.
- `sound-effects-cues.json`: توقيت مؤثرات الانتقالات والكتابة والإنجازات والإشعارات.
- `DESIGN.md`: الهوية البصرية والتوقيت.
- `storyboard.jpg`: معاينة المشاهد التسعة.

## إعادة التصدير

يتطلب Node.js 22.12 أو أحدث، Chrome، وFFmpeg/FFprobe متاحين في PATH.

```sh
npx --yes hyperframes@0.8.136 check
npx --yes hyperframes@0.8.136 preview --background
npx --yes hyperframes@0.8.136 render --output Kodax-SFX-NoMusic-1080x1920.mp4 --fps 30 --quality high --workers 1 --strict-all
```

الواجهة هي HyperFrames Studio. النصوص RTL داخل المحتوى فقط، لسلامة إخراج MP4.
صور التطبيق مرجعية قدمها المستخدم. المؤثرات الصوتية مؤلفة إجرائياً لهذا الفيديو؛ لا تحتوي موسيقى أو عينات صوتية خارجية. خط Cairo مرفق مع ترخيص SIL Open Font License.
